## Thay đổi

- Manifest phân biệt source-part và canonical-subpart, Raw chỉ được load một lần mỗi raw_path. Giữ source_record_key và source_row_number cũ, không đổi grain hoặc duplicate policy.
- Exporter kiểm actual length của từng part; giữ attempted counters để tương thích nhưng bổ sung inserted/conflicted thật từ PostgreSQL. Technical quarantine cũng có write counters riêng.
- Stage verification đối chiếu footer/local/DB, kiểm key partition Raw = Canonical UNION DISJOINT Technical, coverage source_row_number, batch/version/file/SHA/schema/month. Không còn cho PASS chỉ vì ba tập cùng thiếu dòng hoặc cùng rỗng.
- Verify failure ghi STAGING/batch FAILED; không gọi commit watermark. Unknown/missing columns và retry khác payload/scope FAIL rõ ràng, không bị ON CONFLICT che.
- Canonical xử lý fractional integer/overflow/nonfinite, giữ original source payload cho lỗi optional lẫn reject. Giá trị âm nghiệp vụ không bị đổi thành reject kỹ thuật.
- Typed Raw có đường projection NULL + original payload cho trường sai kiểu; migration nullable payload chuẩn bị tại `sql/migrations/008_mage_raw_cast_payload.sql`. Chưa chạy migration live; chưa có cột thì error rows FAIL closed, healthy input vẫn tương thích.
- COPY phân biệt SQL NULL, chuỗi rỗng, literal backslash-N, quote/comma/newline. Guard cleanup canonical directory ở phạm vi batch/work root.
- Thêm structured phase timing, không log dữ liệu nguồn hoặc credentials. Chưa thực hiện direct COPY/reuse connection của M02–M03.

## Kiểm chứng

**29 tests PASS** (18 tests sẵn có và 11 tests bổ sung), chạy suite opt-in PostgreSQL trong Mage container; xem `M01_tests.log`. Tests tạo schema UUID chỉ dùng cho QA, clone table structure/indexes/checks/identities, thêm payload column trên bản QA, không ghi control hoặc staging/DQ live; schema QA được drop sau mỗi suite.

Các tình huống đã kiểm: schema v001/v002/CBD, optional cast original, required reject/reject-all, integer fractional/overflow, numeric nonfinite/overflow, partial loss dù tổng vẫn cân bằng, wrong partition/scope/footer, retry giống nhau có số inserted/conflicted đúng, retry khác payload FAIL, duplicate keys trong input FAIL, thiếu/unknown columns FAIL, NULL/text round-trip, split source/canonical chunk khác size và actual exporter không load Raw lặp. Kiểm tổng total_amount Raw = Canonical + Technical trên fixture numeric eligible. Test verify failure không ghi success.

Các lỗi bắt được trong QA đã sửa trước khi đóng: NULL sentinel dài bị pandas 1.5 truncate khi serialize numeric, và dependency pgcrypto chưa có trong DB hiện tại. Sentinel được giới hạn độ dài/collision-check; validator dùng sha256 built-in của PostgreSQL 16.

## Giới hạn và bàn giao

- Full DDS, rule coverage dbt, schedule, crash recovery UNLOGGED, replacement/new-batch orchestration chưa được nghiệm thu bởi M01; tiếp tục M06 và T06/T08/T09. Không coi test QA schema clone là full FK/constraint/orchestration QA vì LIKE không tự sao chép FK.
- Nullable payload được dbt fingerprint reader hiện hữu hỗ trợ bằng `to_jsonb(r)`/payload fallback; chưa chạy full dbt integration với các lỗi này trên live.
- Conflict kiểm tra cột input, không kiểm generated/default timestamps. Retry batch mới không được tự dùng rows batch cũ; runner phải thực hiện quy trình recovery scope tương ứng.
- Stage verification hiện đọc/nhóm full keys, có thêm chi phí correctness; tối ưu sau dựa trên telemetry, không bỏ kiểm tra để đạt 2–4 phút.
- Raw lỗi vẫn phải qua schema registry/approval upstream; hỗ trợ type lỗi không có nghĩa chấp nhận schema fingerprint bất kỳ.
